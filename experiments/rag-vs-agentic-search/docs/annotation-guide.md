## 多 gold

- 只拿查询文本与语料树，不看任何方案输出、得分或排名（`blind: true`）。
- 记录"回答该症状需要读哪些文件"，不排序、不分级。
- 单标注者时报告必须写明"无一致性系数"，nDCG@5 标低置信。

## 扰动集

| 档位 | 允许 | 禁止 |
|---|---|---|
| 同义改写 | 替换非术语措辞 | 改寄存器名/错误码/外设名 |
| 错别字 | 中文非 token 字符 1-2 处形近替换 | 改英文标识符、十六进制、型号 |
| 口语化 | 加口语连接词与冗余 | 引入新事实或症状细节 |

三档各 50 条，固定 seed 从 274 条中分层抽样；生成后人工过目，`reviewed=true` 才进入评分。

## 负样本

三类来源：KB 有相近主题但无对应症状文件 / 型号或外设未覆盖 / 问题非 KB 可答。
判据是**所有方案都应显式拒答**；标注 `near_domain` 区分"领域相近"与"完全无关"。
