## 2026-10-19 · 事故：误触发 npm install

- **经过**：用 `node -e "..."` 追加本文件时，命令字符串内含 Markdown 反引号；反引号被 bash 当作命令替换执行，其中一段为 `npm install`，导致 npm 实际运行一次。
- **后果核验**：`git status` 无 package-lock.json 变更（内容未变），`node_modules` 目录 mtime 未变（09:56），依赖树未发生实质变化；未生成/修改任何被跟踪文件。
- **纠正**：后续写入改用 `node - <<'EOF'`（单引号 heredoc，禁止展开）或 edit 工具；不再在双引号 shell 字符串中放置反引号。
- **自评**：违反「禁止 npm install」约束，须在 task-2-report 与最终回复中显式报告。
