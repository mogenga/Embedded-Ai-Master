## Task 11 修复：收紧检索匹配以支持拒答（2026-10-20）

**用户关键原话**：「负样本 refusalRate 只有 0.16（4/25），即 84% 的 KB 外查询被 `kb_lookup` 误判为有命中，不满足 BR-3『KB 外查询有显式拒答』的验收方向。不能把低拒答率当作可接受基线」「禁止针对特定负样本 id/路径硬编码，禁止修改语料、queries.jsonl、negatives.jsonl」「英文 keyword/tag 使用词边界匹配；忽略长度 < 2 的纯英文 keyword/tag；按 df 降权；可选最小置信门槛」「若 Recall@2 下降超过 5pp，必须说明权衡」。

**误报根因（21 条误报，详见 report 附表）**：

- 单字符英文 tag `c`：`system/toolchain/c-level-optimization-bugs.md` 的 tag `c` 用 `includes` 命中任意含字母 c 的英文串，直接造成 neg-015/016/018/019/021/024 误报，也污染 neg-004/009 的候选。
- 英文无词边界：`rtos` 命中 `freertos`、`nrf`/`nrf52` 命中 `nrf52840`、`esp32` 命中 `esp32-s3`；同一 token 同时在 keyword 与 tag 里重复计分（`spi`、`can`、`rtt`、`modbus`、`dma`、`cache` 等）。
- 宽泛技术词与通用中文症状/问句词：`spi`(df=6)、`can`(df=2)、`收不到`、`没反应`、`怎么算`、`优化`；单命中即可越过旧实现的无门槛判定。
- 邻近主题但细节未覆盖：`zephyr/devicetree`、`modbus`、`dma/cache`、`esp32`、`nrf52840` 等词面与 KB 条目真实重合，纯词法无法判断“能否回答细节”，只能靠置信度收紧。

**实现（`mcp-servers/kb/service.ts`）**：

1. 非 CJK token 改为 ASCII 词边界匹配（前后不得是 `[A-Za-z0-9_]`）；中文仍用子串。
2. 纯英文长度 < 2 的 keyword/tag 直接忽略（`c` 不再命中）。
3. tag 权重从 3 降为 2，降低宽泛主题标签与同 token 重复计分的影响。
4. 查询侧置信度：统计查询中长度 ≥ 2 的 ASCII/十六进制 token，计算未出现在索引 keyword/tag 词表中的比例 `oovRatio`，分数乘以 `max(0, 1 - 0.75 × oovRatio)`。索引词表是 KB 自己声明的覆盖范围；KB 外查询往往带有大量未登录的型号/外设/流程 token。
5. 折减后最高分低于 **1.75** 时返回 `found: false`、`reason: "low_confidence"`；无任何词面命中仍返回 `no_match`。阈值取在满分 2 分（一个 2 字中文关键词）之下，允许单条完整证据，拒绝被 OOV 折减后的弱证据。

**未采用 df 降权的原因**：`weight = length / (1 + df)` 与阈值组合在 Recall@2 不低于 0.43 的约束下最多只能把拒答率提到约 0.28；要进一步提拒答就必须把阈值抬到 Recall@2 ≈ 0.20。负样本多命中 df=1 的型号/厂商 token（`risc-v`、`modbus`、`nrf52840`、`zephyr`），df 降权对它们无效，却会压低 `uart`/`spi` 等 KB 内合法高频词。

**修改前后（2026-10-20 实测）**：

| 指标 | 修改前 | 修改后 | 变化 |
|---|---|---|---|
| index Recall@2 | 0.48 | 0.46 | -2pp |
| index Hit@1 | 0.40 | 0.40 | 0 |
| index MRR | 0.44 | 0.43 | -1pp |
| search Hit@1 | 0.4333 | 0.4333 | 0（本轮未改 search） |
| negatives refusalRate | 0.16（4/25） | 0.56（14/25） | +40pp |

阈值扫描（同一评分规则）：thr 1.0 → Recall 0.48 / 拒答 0.52；1.5 → 0.46 / 0.52；1.75 → 0.46 / 0.56；2.0 → 0.44 / 0.56；2.25 → 0.32 / 0.56；3.0 → 0.30 / 0.64。选择 1.75：Recall 只降 2pp（<5pp），Hit@1 不变，拒答率提升 40pp；若更看重召回，1.0 可保持 Recall 0.48 且拒答 0.52。阈值基于分数分布而非负样本 id。
