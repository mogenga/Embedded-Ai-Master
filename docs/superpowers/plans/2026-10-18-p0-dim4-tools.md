# P0 维度 4 工具系统实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 `fs`/`shell`/`glob`/`grep` 四个内置工具并接入 `runSession`, 保留现有五阶段管线、结构化错误与 workdir 安全边界。

**Architecture:** 新增 `path-safety.ts`(workdir 边界)与四个工具文件; `builtin.ts` 汇总注册; `runSession` 用 `createBuiltinTools()` 并传 `cwd = opts.cwd ?? process.cwd()`; 所有工具复用 `ToolDef/ToolResult` 与管线超时/截断。

**Tech Stack:** TypeScript + Node 24(ESM-only)、Zod v4、vitest v4。不新增依赖。

**Spec:** [2026-10-18-p0-dim4-tools-design.md](../specs/2026-10-18-p0-dim4-tools-design.md)

## Global Constraints

- Node >= 24, ESM-only, strict, 相对导入 `.js`; 不新增依赖; 不加代码注释。
- 所有路径必须经 `resolveInWorkdir(ctx.cwd, input)`; 拒绝 `..`、绝对路径外部、symlink 越界。
- shell 是 workdir + 危险命令拦截, **不是沙箱**; 非零退出码不算 `isError`。
- 工具结果走现有管线截断/落盘; 错误是结构化数据。
- Windows 一等公民: `node:path`、大小写不敏感比较、跨平台 `node -e` 测试。
- 每任务 TDD: 先失败测试 → RED → 最小实现 → GREEN → 全量验证 → 提交。
- 分支 `feat/p0-dim4-tools`; 不合并 `main`; 依赖安装由用户手动执行。

## Review Focus

1. `resolveInWorkdir` 对 `..`、绝对路径、symlink 父目录/文件逃逸全部拒绝。→ Task 1
2. `fs write/edit` 不得写到 workdir 外; edit 多处匹配必须拒绝。→ Task 1
3. `shell` 危险命令不 spawn; cwd 越界拒绝; 非零退出码保留且不标错。→ Task 2
4. `glob`/`grep` 不跟随 symlink; `**/*.ts` 匹配根级; 结果路径相对 workdir。→ Task 3/4
5. `grep` 跳过二进制/超大/不可读时在 text 披露, 不静默。→ Task 4
6. `runSession` 工具根用用户工程 `process.cwd()`, 不是会话目录。→ Task 5
7. resume 时 `opts.cwd` 与 `header.workdir` 冲突 → `workdir_mismatch`。→ Task 5
8. 5 个工具 schema 进模型请求且名称合法。→ Task 5
